# Dragon Professional Speech Tools

Dragon Professional is a speech recognition utility designed to turn spoken language into written documents and help users manage text through voice commands. It supports professional dictation, recorded-audio transcription, document correction, and reusable commands for repetitive writing tasks.

## Overview

Dragon Professional converts spoken words into text and provides voice-driven tools for creating, correcting, and formatting documents. It is designed for professional environments where accurate documentation and efficient text entry are important.

Users can dictate directly into compatible applications, work with recorded speech, and create custom voice commands for frequently repeated actions. Specialized vocabulary and reusable text blocks can help maintain consistency across documents.

## Key Features

| Feature | Description |
| --- | --- |
| Speech Recognition | Converts spoken language into written text. |
| Voice Dictation | Supports document creation through spoken input. |
| Audio Transcription | Converts supported recorded speech into text. |
| Voice Editing | Provides commands for correcting and formatting dictated text. |
| Custom Voice Commands | Automates selected actions and repetitive workflows. |
| Reusable Text Blocks | Inserts standard phrases, signatures, and document content. |
| Specialized Vocabulary | Supports terminology used in professional fields. |
| Document Formatting | Uses supported spoken commands to format text. |
| Batch Transcription | Processes supported recordings through available transcription tools. |
| Application Integration | Works with compatible text editors and productivity applications. |

## Use Cases

Dragon Professional can support professional correspondence, reports, case documentation, administrative records, and other writing-intensive tasks. Voice dictation can also assist users who prefer speech-based text entry.

Recorded-audio transcription is useful when written records must be prepared from supported speech recordings. Custom commands and reusable text blocks help standardize recurring documentation tasks.
